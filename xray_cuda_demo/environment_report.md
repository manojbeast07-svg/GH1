Status: **AVAILABLE — with a caveat.** `nvidia-smi` reports the driver's maximum
supported CUDA (runtime API) version as **13.2**, while the installed toolkit
(`nvcc`) is **13.3**. In practice this combination built and ran correctly end
to end in this project (CUDA runtime is generally forward-compatible within a
major version series), so it is not blocking, but it is flagged here as a
**version-skew risk** rather than silently ignored. If unexplained runtime
errors appear later, this mismatch is the first thing to check — the fix
would be either a driver update or pinning the toolkit to 13.2.
